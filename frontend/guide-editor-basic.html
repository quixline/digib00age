Basic Editor

Quick metadata edits for a single issue, right from the reader.

Opening the Basic Editor

From any issue's page (/issue/{id}), click the Edit XML button in the metadata column. The Basic Editor opens as a modal overlay right on top of the issue page — there's no navigation away and no new tab, so you're back where you started the moment you close it.

It only ever edits the single issue you opened it from. There's no folder picker and no batch option here — for editing several files at once, or files that aren't in your library yet, see the Full Editor instead.

Fields — Main and More tabs

The form is split across two tabs so the fields you'll touch most often aren't crowded by the ones you'll rarely need.

Main tab

  • Series Title and Issue Title — plain text.
  • Issue Number and Year — plain text/number fields. (There's no Increment Number control here — auto-incrementing an issue number only makes sense across a batch of files, so that control lives in the Full Editor only.)
  • Genre — a multi-select checkbox grid, drawn from the Genre list Admin → Editor Options manages. Required — at least one box must be ticked before you can save.
  • Format — a dropdown, also Admin-managed, and required.
  • Age Rating — a dropdown of eight fixed values (Everyone, Early Childhood, Everyone 10+, PG, Adult, Teen, Teen+, Mature) — this list is locked and isn't editable from Admin. Required.
  • Black & White — a plain checkbox.
  • Summary — a multi-line textarea.
Tip

If an issue's existing Genre, Format, or Age Rating value doesn't match the currently-enforced list (usually because it was tagged before that list existed, or the value was later removed from the list in Admin), that field loads blank rather than pre-selected — you have to actively pick a valid value for it before you can save. This applies per field, so a stale Genre won't block saving if Format and Age Rating are already fine.

More tab

  • Count — total issue count for the series, if known.
  • Page Count — auto-counted from the archive's actual image count, but editable if you need to override it.
  • Writer and Penciller — free-text, comma- separated for multiple names.
  • Publisher — plain text.
  • Story Arc — plain text.
  • Language — free text, backed by a datalist of common languages so it autocompletes as you type without restricting you to the list.
  • Notes — plain text; defaults to "Modified with the CAPT" if you leave it blank.

Saving, validation, and canceling

The Save button stays disabled until Genre, Format, and Age Rating are all validly set — there's no way to submit the form with any of those three left unresolved.

Saving is asynchronous: the modal closes immediately once your edits are validated and merged into the file's XML, and a toast notification tracks the rest of the work in the background ("Saving in background…", then "Saved" once the archive rebuild and library rescan finish). You're free to keep browsing while that happens. If you try to save the same issue again while a save is still in flight, the second attempt is blocked until the first one finishes.

Tip

If the Writer or Penciller name you typed is a close match to someone already credited elsewhere in your library, a confirmation popup offers to use that existing spelling instead — a small guard against near-duplicate credits (e.g. "Alan Moore" vs. "Allan Moore") splitting one person into two. It doesn't block the save either way; you can decline and keep what you typed.

Cancel, the × button, or clicking outside the modal all close it without saving anything.
