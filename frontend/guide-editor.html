Editor

Two ways to edit a comic's metadata — pick the one that fits.

Which editor do I need?

Both editors write to the same place — the ComicInfo.xml record packed inside a comic's CBZ file — and share the same enforced Genre, Format, and Age Rating lists, so nothing you set in one editor conflicts with the other. What differs is scope: how many files you're touching at once, and whether those files are already in your library.

Basic Editor is a quick, single-issue fix. Open it straight from an issue's page in the reader when you just want to correct that one issue's title, tick a missing genre, or tweak the summary — no file browsing, no batch controls, just the issue you're already looking at.

Full Editor is a batch tagging workspace for handling many files at once — built mainly for tagging new comics before they join your library (e.g. a staging folder full of freshly-downloaded issues that haven't been scanned in yet), but also useful afterward: select one or more already-catalogued issues from the library and use Send to Full Editor to load them in for a batch retag. Open it from Admin → Open Editor, or from a library selection's "Send to Full Editor" action in the selection bar.

Rule of thumb: editing one issue you're currently reading or viewing → Basic Editor. Editing several files at once, or files not yet in your library → Full Editor.
