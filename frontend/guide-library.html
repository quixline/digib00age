Library

Browsing, reading, and organizing your comics.

The library index

The Home page greets you with a set of scrollable strips — Continue Reading (when you have something in progress), Recently Added, Random Unread, Random Genre, and any custom strips your admin has added. Click a strip's heading (where it's a link) to open the full filtered list behind it, or use the left sidebar to jump straight to Series (multi-issue titles only), Singles (one-shots), or All (everything together). The Unread, Reading, and Read shortcuts in the sidebar each open the All view pre-filtered to that status.

Every browse surface shares the same toolbar above the cover grid:

  • Search — live search scoped to whichever surface you're on.
  • Sort (A–Z, Newest, Recent, Issues, Pages) with an ascending/descending toggle next to it.
  • A grid/list view toggle — list view adds genre tags, publisher/writer, a summary snippet, and a "% Read" figure in place of the progress bar.
  • Rated, Favourites, and Flagged filters, plus secondary filters for Genre, Format, Decade, Year, Rating, and B&W.
  • Group By (Year, Genre, Publisher, Writer, Format) — available on the flat Series/Singles/All surfaces.
  • A Clear Filter pill that resets every active filter, sort, search, and grouping at once — it only appears once something is actually active.

A live item count sits at the top-right of the toolbar, and once a filter is active it's replaced by a banner showing what you're filtered to, with its own Clear link.

Each cover card shows the title, year, a genre tag, and either an issue count (series) or page count (singles), along with your star rating if you've set one. A small dot badge in the corner marks an issue as fully read, a flag badge marks one flagged for review, and a progress bar along the bottom fills in as you work through a series or a single issue — an empty bar means unread, a partial bar means you're mid-way through, and a full bar (or the read-state dot) means finished.

Folder View

Some libraries in the sidebar are set up as a Folder View instead of a flat list — rather than one long grid, they mirror the actual folder structure on disk. Subfolders show up as their own cards (with a representative cover and a recursive issue count for everything inside), and clicking one drills down a level; use your browser's Back button to go back up. It's the same toolbar as everywhere else, minus Group By and the Pages sort option, since neither means much once things are split across folders.

Searching inside a Folder View library replaces the current folder's grid with a flat list of matches from anywhere in that library, each showing its folder path — clearing the search brings back the folder you were browsing.

The series page

Opening a series shows a header with its publisher, year, genre tags, and issue count, plus a Mark all read button that marks every currently-unread issue in the series done in one go. Below that is the full issue list — each row shows a thumbnail, issue number and title, year and page count, genre tags, and a short summary. Click the status icon on a row (○ unread / ▶ reading / ✓ read) to toggle that single issue's read state without opening it.

Click an issue row's title or cover to open it for reading. To edit its metadata instead, open the issue and use its Edit XML button, which opens the Basic Editor.

The issue page

The issue page shows the cover, the series title, issue number, format and B&W badges, publisher/year/language, genre tags, a summary, story arc (if set), and Writer/Artist credits — each credit name links to everything else by that person.

The cover art and the Start Reading / Continue Reading / Read Again button both do the same thing: they hand off to the digib00age reader app to actually open the pages.

Tip

Reading opens in the separate digib00age reader app (Windows or Android). If that app isn't installed on the device you're using, clicking Read won't do anything visible — install the reader app first.

From here you can also toggle Mark as Read, add the issue to Favorites or the Reading Queue, set a 1–5 star rating (click your current rating again to clear it), Flag for Review, or open Edit XML to change its metadata. A prev/next bar at the bottom moves between neighbouring issues in the series, when one exists.

Selecting items and bulk actions

You can act on several issues (or whole series) at once. Start a selection by long-pressing any card or row, clicking the select-dot that appears on hover (grid view), or Shift-clicking a second card to select a range. Selecting a series card (not a Singles card) selects every issue in that series. Once selection mode is active, a floating toolbar gives you:

  • Mark Read / Mark Unread — bulk status change.
  • ★ Favorite — favourites everything selected, or un-favourites if all of it already was.
  • 📖 Queue Reading — same on/off logic, for the Reading Queue.
  • 🏷 Flag for Review — same logic, for the review flag.
  • → Send to Full Editor — opens the selected issues in the Full Editor for XML editing.
  • A star rating row — sets a rating across the whole selection; clicking a rating everything already has clears it instead.
  • Deselect — clears the current selection but stays in selection mode; Done exits selection mode entirely.
Warning

Delete permanently removes the selected file(s) from disk and their database record(s) — there's a confirmation prompt first, but once confirmed, there's no going back.
