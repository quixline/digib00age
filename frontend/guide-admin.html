Overview, Stats & Live Scan

The Admin page (accessible via the gear icon in the top header) is the command center for server scanning, backups, appearance, access rules, and file processing tools.

Library Stats & Scan Controls

  • Library Stats: Read-only summary cards showing Total Files, Series, Singles, Total Read (count & percentage), and In Progress issues.
  • Library Scan Logs: Cards for Last Scan date, Files Found, and New Files. Each features a Logs button opening recent scan entries. A card's border turns green when unviewed log entries exist — opening the log modal clears the badge.
  • Scan Now: Triggers an immediate rescan of all configured roots. Shows live progress, scanned counts, and reports thumbnail errors if any occur (affected files are still catalogued).

Top Action Row

A quick-action bar above the stats handles common administrative utilities:

  • Back: Return to the library view.
  • User Guide: Open this documentation.
  • Open Editor: Launch the batch Full Editor in the current tab.
  • Backup Database: Trigger an immediate manual database snapshot to your configured backup folder.
  • Password Reset: Change the active admin password (requires existing password).
  • Forgot Password?: Displays local recovery steps (stop server process, clear stored password fields in config.json, restart).
  • Install App: Install digib00age as a Progressive Web App (PWA) on your desktop or mobile device.

Library Management

Configure directory roots, automated rescanning schedules, access logs, and database snapshots.

Auto Scan Settings & Folders

Auto Scan Schedule: Choose automatic scan intervals (Off, 1 hour, 6 hours, 12 hours, 1 day, 3 days, 7 days, 1 month) and toggle Scan on launch to force a rescan whenever the server starts.

Library Folders & Exclusions: Define top-level Scan Roots for digib00age to index. Add directory names or glob patterns to Exclude Patterns (e.g. Processing) to prevent staging folders from appearing in the main library.

Database Backups & Restoration

DB Backup Schedule: Pick a local backup folder (via native folder picker) and frequency (Off, Day, Week, Month, 6 Months, Year). Displays last backup timestamp or error indicators.

Tip

Select a local cloud-sync folder (e.g., Google Drive, Dropbox) for automatic off-site backup protection!

Restore DB: Restore a previously saved .db file snapshot. Overwrites database state and restarts the server after automatically creating a safety snapshot of the current state.

Warning

Restoring replaces your entire database (including custom libraries and home strips). Local sessions only.

Access Logs & Size Limits

View the disk directory path where scan and processing log files are saved (with a one-click Copy button) and configure Log Size Limit (MB) to automatically cap log file size on disk.

Library Appearance

Customize the visual layout, Home page strips, card sizing, and custom libraries.

Home Page Strips & Custom Libraries

Home Page Strips: Reorder or add up to 5 custom scrollable strips on the Home view. Custom strips can be Field-based (e.g. Genre = Horror) or Folder-based, sorted randomly or fixed by Title/Newest/Recent.

Add/Remove Libraries (Custom Tabs): Create custom sidebar views with Flat (grid) or Folder View (directory hierarchy) modes. Quick shortcuts allow adding Genre, Favorites, or Reading Queue libraries with one click.

Theme, Card Sizing & Pagination

Theme Selection: Switch between Match Windows (auto OS preference), Light, or Dark theme instantly.

Card Size: Adjust cover card grid scale from 30% to 100% across all browse grids and Home strips.

Pagination: Set browse items per page (25, 50, 100, 200, 500; default 50).

Editor Options

Managed Value Lists (Genre & Format)

Manage the enforced dropdown values used in both Basic and Full Editors:

  • Genre List: Add/remove options offered in the Genre selector. At least one genre must exist. Removing an in-use genre does not untag existing issues; it only stops future selection.
  • Format List: Add/remove supported formats (e.g. Single Issue, TPB, Graphic Novel).

Advanced Settings

Tip

All Advanced Settings require ticking the Unlock checkbox before modification to prevent accidental changes.

Security & Port Settings

Password Protection: Enabling Require a password gates Admin and Editor pages behind local authentication. Allow Remote Administration permits LAN devices to access settings when password protected.

Change Server Port: Modify the listening HTTP port and click Save & Restart.

Warning

Changing the server port restarts the server immediately. Relaunch the tray app so menu shortcuts reflect the new port.

Database & Progress Wipe Tools

Wipe Database: Permanently deletes all catalogued issues, genres, credits, and progress records (does not delete comic files on disk). Local sessions only.

Wipe Reading State: Resets all issue reading progress to unread while preserving metadata and catalog records.

Processing Tools (Local Sessions Only)

Pre-ingest filesystem management tools for preparing comic archives before or alongside library scans.

Filename Editor

Batch renames comic files based on parsed or edited Series, Issue, Title, and Year values:

  • Folder Picker: Select any directory on the server machine.
  • Batch Controls: Edit fields individually per file or check All to apply a value across the entire loaded batch.
  • Auto-Increment Issue Numbers: Automatically sequence issue numbers sequentially down the list.
  • Queue & Preview: Review original vs new filenames in the Queued Files preview before committing. Click Apply Rename to commit changes on disk.
Archive & Image Converter

Convert Archives: Convert CBR or PDF archives directly into standard CBZ format with progress tracking.

Convert Images: Repack archives with compressed WebP images. Set quality (1–100) or check Lossless. Automatically preserves .bak files if any unreadable pages are encountered during conversion.

XML Tagging & ComicVine Key

Matches comic files in a target folder against ComicVine and writes ComicInfo.xml into each archive:

  • Match Ratio Threshold: Set required confidence percentage (10–100%, default 80%).
  • Save on Low Confidence: Writes low-confidence matches flagged with a review tag rather than skipping them.
  • ComicVine API Key: Enter your personal API key with Save & Test validation to avoid rate limits.
Folder Processing & Auto Processing Pipeline

Folder Processing: Run one-off sorting scripts: Sort by Filename (moves loose CBZs into title subfolders), Move Series Folders, or Move Singles Folders.

Auto Processing Pipeline: Automate pre-ingest staging on a folder schedule. Runs in fixed sequence: Convert Archives → CT Auto-Tag → Convert Images. Filename renaming is deliberately excluded for human verification safety.
