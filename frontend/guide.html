ComicVault is your personal home-network comic server.


Browse — Use the Home, Series, Singles and All tabs to explore your collection.

Read — Open an issue and tap Read to launch the ComicVault Flutter app.

Custom Tabs — Admin-managed, folder-scoped tabs. Folder View mode browses a folder's own structure (e.g. by year) with recursive search and mark-all-read.

Admin — Trigger a library rescan, back up the database and manage settings via the gear icon.

Forgot your Admin password? — Recovery is local-disk-only: stop the server, open config.json and clear the admin_password_hash and admin_password_salt fields, then restart. This turns protection off; set a new password from Admin → Advanced Settings as normal.
