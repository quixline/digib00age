Installing digib00age

Pick the platform that matches your setup — more detail than the quick Downloads section on digib00age.cc.

Quick Jump:
Windows Linux Docker Android First Steps

digib00age is self-hosted — you run it on your own hardware, there's nothing to sign up for and nothing phones home. Each platform below has its own install path; pick whichever matches the machine you want running the server. Your Android device is always just a reader connecting to one of these — never the server itself.

Windows

Ships as a per-user MSI installer — no administrator rights needed, nothing installed system-wide. It unpacks to %LocalAppData%\Programs\digib00age and runs from the system tray.

  1. Download digib00age-setup.msi from the Downloads section on digib00age.cc (or this project's GitHub Releases) and run it.
  2. Windows SmartScreen may flag it as unrecognized — the installer isn't code-signed yet. Choose More info → Run anyway to continue.
  3. On first launch, Windows Firewall asks whether to allow digib00age-server through public and private networks. Leave Public unchecked and Private checked, then Allow — this is a home-network server, not one you want reachable from a public wifi.
  4. The server starts from the tray and opens your library in a browser from the tray menu.
Tip

Right-click the tray icon any time for Open Library, Admin, Metadata Editor, Start/Stop Server, and a login-autostart toggle.

Linux

Download the Linux release, unzip it, and run the install.sh inside. It checks for the system packages digib00age needs — and tells you exactly what's missing if anything is — then creates a private Python virtual environment, installs digib00age into it, and sets up an Applications-menu launcher.

Prerequisites (install.sh checks these automatically and fails fast with instructions if anything's missing):

sudo apt install python3 python3-venv build-essential python3-dev python3-gi gir1.2-gtk-3.0 libayatana-appindicator3-1 gir1.2-ayatanaappindicator3-0.1 python3-icu

Those are Debian/Ubuntu package names (apt) — distros on a different base (Fedora, Arch, openSUSE) will need their package manager's equivalents; install.sh will still tell you what's missing either way.

Tip

Confirmed working on Linux Mint 21.3 and 22.3 (Cinnamon) and Ubuntu 22.04/26.04. Other Debian/Ubuntu-based distros are very likely fine too — just less directly tested.

Docker

Prefer a container? Any OS that runs Docker works, with no Python environment to manage. New to Docker — see docker.com for what it is and how to install Docker Desktop (Windows/Mac) or Docker Engine (Linux) first.

  1. docker pull ghcr.io/quixline/digib00age:v1-beta
  2. Download docker-compose.yml from the Downloads section, and edit its one volumes: line if your library isn't under /mnt.
  3. docker compose up -d
Tip

No gated setup wizard — open http://<host>:9800/admin as soon as it's up, add your library folder under Library Folders, and set a password there if you want to require a login. It's open to anyone who can reach the port until you do, same as every other install path.

First Steps After Installing

Once the server's running, open it in a browser — on Windows, right-click the tray icon and choose Open Library; on Linux or Docker, visit http://localhost:9800 (or the host's address from another device). Go to Admin → Library Management → Library Folders, add the folder(s) where your CBZ/CBR files live, and scan. From there: the homepage is your library, /editor is the Full Editor for batch-tagging new comics before they join it, and the Library guide and Admin guide cover everything else.
