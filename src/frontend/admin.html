      Forgotten your password? There's no in-app reset —
          recovery is manual and requires local access to the machine running
          digib00age:
      
        
        
          
      1. Stop the digib00age server.
        2. 
          
      2. Open config.json in a text editor.
        3. 
          
      3. Delete the values for admin_password_hash and
            admin_password_salt (set both to null, or
            remove the lines entirely).
        4. 
          
      4. Save the file and restart the server.
        5. 
          
      5. Password protection is now off. Go to Advanced Settings and set a
            new password as normal.
        6. 
        
      
        
      This is by design: clearing protection requires
          physical/local access to the machine, which is the same trust boundary
          password protection itself relies on.
