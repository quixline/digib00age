Everything you need to browse, read, and manage your digib00age library.

digib00age is your personal, self-hosted comic library — it scans a folder of CBZ/CBR files on your network and turns them into a browsable, searchable library with automatic reading progress, ratings, and metadata you control. Use the navigation sidebar or quick links below to explore each area:

Library & Web Reader

Browse your collection by series, single-issue titles, or custom folders. Features an in-browser Web Reader with tap zones, Manga/Right-to-Left mode, zoom/pan, keyboard shortcuts, active filter chips, reading queue, and bulk management.

Open Library Guide →

Admin & Settings

Set up scan roots, auto-scan frequencies, database backup schedules, themes, card sizes, and local password protection. Includes built-in Processing Tools for batch renaming, archive/image webp conversion, and ComicVine auto-tagging.

Open Admin Guide →

Editor Hub

Two ways to fix or fill in a comic's metadata: a single-issue Basic Editor right inside the browser, and a 4-column batch-tagging Full Editor for staging new files before they join your library, complete with ComicVine and GoodReads integrations.

Open Editor Hub → • Basic Editor • Full Editor

Tip

New here? Start with Library to learn your way around browsing and reading, then check Admin once you're ready to set up your own folders.
