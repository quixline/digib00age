Which editor do I need?

Both editors write to the exact same ComicInfo.xml file embedded inside comic CBZ archives and share enforced Genre, Format, and Age Rating lists. What differs is scope and workflow:

Feature Basic Editor Full Editor
Primary Scope Single issue metadata edit Batch tagging (entire folders or selection)
Access Point Issue Detail page (Edit XML) Admin → Open Editor or Selection Bar
Pre-Library Staging No (requires library item) Yes (edits files before scanning)
Integrations Near-duplicate credit checks ComicVine online lookup & GoodReads extension
Batch Utilities N/A Auto-increment numbers & "Apply to All" fields
Page Viewer Cover preview 4-column layout with full zoom/pan page viewer

Basic Editor →

A quick, single-issue modal. Open it straight from any issue's detail page when you want to tweak an issue title, summary, format, genre tags, or creator credits. Saves asynchronously in the background while you keep browsing.
