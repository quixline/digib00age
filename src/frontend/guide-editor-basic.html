Opening the Basic Editor

From any issue's page (/issue/{id}), click Edit XML in the metadata column. The Basic Editor opens as a modal overlay directly on top of the issue page without navigating away.

It edits only the single issue opened. For batch tagging multiple files or staging un-scanned comics, use the Full Editor instead.

Fields Breakdown — Main & More Tabs

Form fields are organized across two tabs to keep primary tagging clean and uncluttered:

Main Tab Fields (Primary Metadata)
  • Series Title & Issue Title: Plain text fields.
  • Issue Number & Year: Plain text/numeric fields.
  • Genre: Multi-select checkbox grid from the managed Admin list. Required — at least one genre must be selected.
  • Format: Dropdown from managed Admin list. Required.
  • Age Rating: Dropdown of 8 standard ratings (Everyone, Early Childhood, Everyone 10+, PG, Adult, Teen, Teen+, Mature). Required.
  • Black & White: Checkbox indicator.
  • Summary: Multi-line summary description textarea.
Tip

If an existing Genre, Format, or Age Rating value is legacy or removed from Admin, it loads blank — requiring you to pick a valid value before saving.

More Tab Fields (Credits & Details)
  • Count: Total issue count for the series.
  • Page Count: Auto-calculated archive image count (editable override).
  • Writer & Penciller: Comma-separated names for creator credits.
  • Publisher: Publisher text field.
  • Story Arc: Optional story arc title.
  • Language: Free-text with common language autocompletion.
  • Notes: Archive notes field (defaults to Modified with the CAPT).

Saving, Validation & Duplicate Safeguards

  • Enforced Field Validation: The Save button remains disabled until Genre, Format, and Age Rating are valid.
  • Async Background Saving: Saving closes the modal instantly and performs archive rebuilding in the background. A toast notification updates status ("Saving in background…", then "Saved").
  • Near-Duplicate Creator Guard: If a typed Writer or Penciller name closely matches an existing creator in your library (e.g. Alan Moore vs Allan Moore), a confirmation dialog offers to standardize the spelling.
