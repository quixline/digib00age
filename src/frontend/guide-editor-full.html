What the Full Editor is for

The Full Editor is a 4-column batch metadata-tagging workspace built mainly as a pre-library staging tool — a place to tag a folder of freshly acquired comics before they enter your main library. You can also load existing catalogued issues from the library using Send to Full Editor in the selection bar for a batch retag.

4-Column Workspace Layout

  • Column 1 — Load / Select Files: Folder tree browser with natural sorting (001 < 002 < 010) and status badges.
  • Column 2 — Edit ComicInfo.xml: Comprehensive form with "Apply to All" batch checkboxes and Issue # auto-incrementing.
  • Column 3 — Comic Viewer: Full page-by-page archive viewer with zoom, drag panning, and thumbnail strip.
  • Column 4 — Edited Files Queue: Save queue manager for queueing edits and running batch saves.

The Four Columns in Detail

Column 1 — Load / Select Files

Click Select Folder to launch digib00age's in-app folder picker. Files are natural-sorted and rendered as a tree with status indicators:

  • XML Badge: Indicates a ComicInfo.xml file is present inside the archive.
  • Needs-Review (Red Border): Visual cue marking files flagged during low-confidence auto-tagging.
  • Stats Row: Tracks total files found, with XML, and without XML.
Column 2 — Edit ComicInfo.xml & Batch Tagging

Tagging fields split across Main and More tabs with batch controls:

  • Increment # Checkbox: When checked, issue numbers auto-increment sequentially across loaded files as you tag through them. For example, load a run of issues, select the first one, tick Increment # and set its issue number, then click Process All — every other loaded file gets the next number in sequence.
  • Apply to All Checkboxes: Each field features an "Apply to All" box. Checking a box stamps that value across every loaded file when running Process All; unchecked fields remain untouched per-file. Handy when one value is shared across a whole run (e.g. tick Apply to All for Genre) but another varies issue-by-issue (leave Summary unticked).
  • Genre Chips: Easily add or remove genre chips drawn from the Admin managed list.
  • ＋ Queue: Adds current file edits to Column 4 save queue. Checks for near-duplicate creator names before adding.
Column 3 — Comic Viewer (Page Preview)

Inspect archive covers or credit pages directly while tagging:

  • Zoom Controls: Zoom in (+), Zoom out (−), Reset (Fit), and Fullscreen.
  • Click & Drag Panning: Click and drag anywhere on the page to pan around when zoomed in.
  • Thumbnail Strip: Bottom strip with lazy-loaded page thumbnails for quick jumping.
Column 4 — Edited Files Queue & Batch Processing

Manages committed edits before writing back to disk:

  • Process Queue: Writes XML edits back to comic archives for all queued files. The queue clears automatically upon completion.
  • Process All: Bypasses the queue and writes XML to every loaded file in Column 1, applying only checked "Apply to All" fields.
  • Clear Queue: Discards pending queue items without saving.
Warning

Process All overwrites fields across all loaded files. Verify checked "Apply to All" boxes before running!

ComicVine Online Search (via ComicTagger)

Click Search ComicVine in the header to look up metadata for the focused file based on Series, Issue Number, and Year (Title is not used in search queries). digib00age talks to ComicVine through the ComicTagger backend, then ranks the results itself:

2-Step Lookup Flow

  1. Select Series: Returns a results table ranked by digib00age's own Best Match scoring (fuzzy title matching, with issue count as a tiebreak) — built on top of the raw ComicVine results to keep the most likely match at the top. Double-click or click Issues to view issue list, or click Ok for single-issue fast path.
  2. Select Issue: Natural-sorted issue list with cover preview. Double-click an issue to confirm and populate form fields.

GoodReads Chrome Extension (Optional)

Scrapes GoodReads book pages and pastes Writer, Penciller, Publisher, Year, Language, Genre, and Summary directly into the focused file form.

Installation & Usage Steps
  1. Navigate to chrome://extensions in Chrome and enable Developer mode.
  2. Click Load unpacked and select the chrome-extension folder inside your digib00age installation directory.
  3. In the Full Editor, click Search GoodReads to search for the book on GoodReads.
  4. On the GoodReads book page, click the extension icon in your browser toolbar to scrape data.
  5. Return to the Full Editor and click the Paste from GR button (labelled with scraped book title) to auto-fill the form!
Tip

Scraped genres are automatically matched against your Admin Genre list (case-insensitive); unrecognised genres are silently skipped to preserve data validity.

Conflict & Failure Resolution Modals

  • Multi-XML Resolution: If an archive contains multiple ComicInfo.xml files, a side-by-side comparison modal asks you to pick which one to keep; excess files are removed on save.
  • Process All Error Summary: If a batch save fails on certain files, an error modal reports per-file failure details so you can fix them individually.
