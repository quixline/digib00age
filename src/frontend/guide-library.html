The library index

The Home page greets you with a set of scrollable strips — Continue Reading (when you have something in progress), Recently Added, Random Unread, Random Genre, and any custom strips your admin has added. Click a strip's heading to open the full filtered list behind it, or use the left sidebar to jump straight to Series (multi-issue titles), Singles (one-shots), or All (everything together). Any Custom Libraries your admin sets up (Admin → Add/Remove Libraries) also appear in the sidebar automatically.

You can toggle the main navigation sidebar at any time using the sidebar toggle (☰) icon in the top header bar. The sidebar also provides quick status filters: Unread (○), Reading (◕), and Read (✓) each open the All view pre-filtered to comics in that state.

Every browse surface shares the same toolbar above the cover grid:

  • Search — live search scoped to whichever surface you're on.
  • Sort (A–Z, Newest, Recent, Issues, Pages) with an ascending/descending toggle next to it.
  • A grid/list view toggle — list view adds genre tags, publisher/writer, summary snippet, and "% Read" figure.
  • Rated, Favourites, and Flagged filters, plus secondary dropdown filters for Genre, Format, Decade, Year, Rating, and B&W.
  • Group By (Year, Genre, Publisher, Writer, Format) — available on flat Series/Singles/All surfaces.
  • Active Filter Chips — each active filter generates an individual chip (e.g. Genre: Sci-Fi ✕). Click the ✕ on any chip to clear just that filter, or click Clear All Filters to reset everything at once.

Each cover card shows title, year, genre tag, issue or page count, and your star rating. Dot badges mark read items, flag badges mark items for review, and bottom progress bars track reading status.

Folder View

Custom libraries in the sidebar can be set up as a Folder View mirroring disk directories. Subfolders show up as cards with representative covers and recursive issue counts; click to drill down, or use browser Back to go up.

Searching inside a Folder View replaces the grid with a flat list of matches from anywhere in that library, showing full folder paths — clearing the search restores your folder position.

In-Browser Web Reader

digib00age includes a built-in, full-screen Web Reader that opens directly in your browser at /reader/{id} whenever you click Read or a comic's cover. No external app installation is required!

Web Reader Features & Controls

  • 3-Zone Tap Navigation:
    • Left 25%: Turn to previous page (or next page in Right-to-Left mode).
    • Middle 50%: Toggle header & footer toolbars visibility.
    • Right 25%: Turn to next page (or previous page in Right-to-Left mode).
  • Manga / Right-to-Left Mode: Automatically reverses tap zones and arrow key directions when issue metadata has manga reading direction set to YesAndRightToLeft.
  • Zoom & Pan: Zoom in (+) up to 300%, zoom out (−) down to 50%, or reset (Fit). When zoomed in, click-and-drag directly on the page to pan around smoothly.
  • Navigation Controls: Interactive page slider, page count indicator (Page X / Y), and Fullscreen button (⛶).
  • Automatic Progress Tracking & Next Issue Prompt: Page turns save progress automatically to the server. Upon reaching the final page, status updates to Read and an "Issue Complete" modal prompts you to jump straight to the next issue (Next issue →) or Stay here.

Web Reader Keyboard Shortcuts

Key Action
← / ↑ Previous page (Next page in Manga RTL)
→ / ↓ / Space Next page (Previous page in Manga RTL)
Home / End Jump to First Page / Last Page
F Toggle Fullscreen Mode
Esc Exit Fullscreen / Close Reader
Tip

In addition to the Web Reader, a dedicated native digib00age reader app is also available for Android, for online or offline reading.

The series page

Opening a series shows its publisher, year, genre tags, issue count, and a Mark all read button. Below is the full issue list showing thumbnails, issue numbers, titles, page counts, genres, and summaries. The same toolbar as the browse surfaces sits above the list, with one difference: the sort dropdown offers Issue # in place of Issues, since you're sorting rows within one series rather than aggregate series cards. Click the status icon (○ / ◕ / ✓) on any row to toggle read status without opening the issue.

The issue page

The issue page displays cover art, series title, issue number, badges, metadata, summary, story arc, and writer/artist credit links. Click cover art or Start / Continue / Read Again to open the built-in Web Reader.

From here you can also toggle Mark as Read, add to Favorites or Reading Queue, set 1–5 star ratings, toggle Flag for Review, or launch Edit XML to open the Basic Editor.

Selecting items and bulk actions

Act on multiple issues or whole series at once by long-pressing cards, clicking hover select-dots, or Shift-clicking range selections. Selecting a series card selects all issues inside it.

  • Mark Read / Mark Unread: Bulk status change.
  • ★ Favorite / 📖 Queue Reading / 🏷 Flag for Review: Toggle flags across selection.
  • → Send to Full Editor: Load selection into Full Editor for batch XML editing.
  • Star Rating Row: Apply star rating across selection (click existing rating to clear).
  • Deselect / Done: Clear selection or exit selection mode.
Warning

Delete permanently removes selected files from disk and database after confirmation.
