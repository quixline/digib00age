Getting the App on Your Tablet

digib00age's mobile reader is a native Android app, built for tablets and phones. It isn't on the Google Play Store yet, so for now it installs as a direct APK (a closed Play Store testing track is planned).

  1. Download the APK — grab the current release link from digib00age.cc, or ask whoever manages your server for a copy.
  2. Open the downloaded file from your tablet's Downloads folder.
  3. Android will likely block the install the first time — allow "install unknown apps" for whichever app you downloaded it through, then try again.
  4. Tap Install.
Tip

Not on Google Play yet — direct APK install is the only way to get it today.

Connecting to Your Server

The first time you open the app, a welcome screen offers two paths: Connect to a Server, or (Android only) Browse Local Files to open a single CBZ straight off the device with no server involved at all.

Connecting takes you to Settings, where you type in your server's address — the same URL you'd use to open digib00age in a browser at home (e.g. http://192.168.1.10:9800). Tap Test Connection to confirm the app can reach it, then Save.

Tip

No account or sign-in step — just a reachable server address. Your tablet needs to actually reach that address, so you'll want to be on the same home network as the server (or back on it via VPN) the first time you connect.

Reading Progress Sync

While you're connected and reading online, your progress updates live, the same way it does in the Web Reader — nothing extra to do.

Downloaded issues work a little differently: since you're reading without a live connection, the app keeps a note of your page and read status locally, then pushes it to your server the next time it gets a good chance to — when you return to your library, or move on to the next downloaded issue. There's no "Sync" button to press.

If you've read the same issue on two devices, whichever update happened most recently wins once the two sides reconcile — nothing gets lost in the process.

Tip

Each downloaded issue shows when it was downloaded, and — while a progress update is still waiting to go out — a small "Not synced" note next to it. That clears itself the next time the app manages to reach your server.

Downloading Issues for Offline Reading

From any series page, tap the download icon beside an issue to save a copy onto the tablet for offline or on-the-go reading. The icon fills in once the download finishes.

Downloaded issues stay available even if the app can't reach your server at all — open the app and they're right there under Downloaded, same as always.

To free up space again, tap the same icon and confirm — that removes only the local copy from your tablet; your library on the server is untouched.

Tip

Only CBZ issues can be downloaded for offline reading today — CBR isn't supported offline yet (the app will tell you if you try). There's also no storage-management screen yet, so it's worth keeping an eye on the tablet's own free space if you download a lot at once.
