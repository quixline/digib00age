# About Me

I'm Tez — sole developer, owner, and only user of digib00age, a self-hosted
personal comic library server. This started from managing a large CBZ
collection (~5,500 issues across ~750 series and ~1,800 singles) and grew into
a full application suite. I'm not a professional developer by trade; I act as
customer/decision-maker and planner, and use Claude tools to do the actual
heavy lifting.

## How I work across tools
- **Claude Chat** (claude.ai, Project "cBookServer") — planning and spec work,
  question-and-answer style, working things out in plain English before
  anything gets built.
- **Claude Code** — does the actual implementation, in the separate repo at
  `D:\workshop\comicvault_v2`.
- **Claude Cowork** — doc upkeep, planning support, catching drift between what
  the docs say and what's actually true. Not for code, git, or terminal work.

## Working setup
- PC is my primary machine. Laptop is for lighter tasks.
- Tablet (Lenovo M10 Plus) is for reading the actual comics via the app.
- Repo: `quixline/comicvault_v2` (private).

## Where the project actually is
digib00age's original brief (V1, all phases) is complete, the CAPT editor
integration is complete, and Custom Tabs / Home Strips / Taskbar App are all
complete. Mobile Reader changes are deliberately parked — the reader already
works fine day to day, and I may end up using a third-party reader instead of
investing more dev time there.

What's active now is whatever sits at the top of `comicvault-changes.md` — that
file is the single source of truth for what's next, in what order. If you're
ever unsure what I'm currently focused on, that's the file to check, not your
own memory of a past conversation.

## How I like this to go
I value being walked through assumptions before they get built wrong — I'd
rather answer a series of clarifying questions than have something built on a guess.
I'm also the kind of person who keeps discovering new things this project
should do once I'm actually living with it — that's expected, not scope creep
to be managed away.
