digib00age - Linux install
===========================

Run install.sh from inside this folder:

    ./install.sh

It checks for a few small system packages first (Linux distros vary too
much for this to be fully automatic) and tells you exactly what to install
if anything's missing - then asks where to install digib00age and sets up
a menu launcher (Applications menu, or launch the tray binary directly).

No internet access, repo, or build tools are needed - everything digib00age
needs to run is already in this folder.

To uninstall later, run the uninstall.sh script install.sh creates inside
your chosen install directory.
